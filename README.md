# OSO Hash of Fame — sealed technical shell

Static front door for `hash-of-fame.opensourceorchestra.org`.

## Release state

This repository intentionally contains **no honoree profiles, personal tributes, remembrance text, photographs, or music**. The site is a quiet, unannounced technical shell with `noindex` metadata and a restrictive `robots.txt`.

Those measures discourage discovery; they are **not access control**. Do not commit sensitive or consent-pending material here. Keep private research and feature previews outside this public repository.

A personal feature may be released only after the required person/circle review and the Open Source Orchestra First Circle blessing. Music and photographs additionally require verified reuse rights, captions, attribution, and a takedown path. Silence is not consent.

## Principles

- Contributions, not rankings.
- Sources before stories.
- Consent before celebration.
- No tracking, wallet, token, paywall, or financial claim.
- Static, accessible, low-cost pages with no runtime dependencies.
